# 网络基础：从地址到数据传输
这是一份为 Study Atlas 试用编写的简短示例，不来自任何用户笔记或视频字幕。

## IP 与 DHCP
IP 地址参与网络寻址。IPv4 地址由 32 位组成，常写成四组十进制数字。设备接入网络时，可以手工设置地址，也可以通过 DHCP 获取地址及其他网络配置。DHCP 解决自动分配配置的问题；它不负责保证应用数据可靠到达。地址示例使用文档用途地址 192.0.2.10，不代表真实网络。

## DNS
DNS 将域名查询映射到包括 IP 地址在内的记录。DNS 解析和连接网站是不同步骤。成功解析域名不保证目标网站可访问；目标服务、网络连接和防火墙仍可能影响访问。并非每次访问都会重新查询远程 DNS，缓存可能提供结果。

## TCP 与 UDP
TCP 提供面向连接的、可靠且有序的字节流，通过确认、重传等机制处理传输问题。UDP 提供数据报传输，本身不保证送达或顺序。使用 UDP 的应用可以自行增加可靠性机制。协议选择应考虑应用需求，不能简单认为 UDP 在所有场景都更快或 TCP 永远更适合。
