# AI 详尽笔记、脑图与自查

每门课程可以成为一个知识主题，按 **学习目标 → 前置知识 → 详尽解释 → 概念 → 课程例子 → 易错点 → 复习问答** 拆成 1 至 6 个模块。

## 使用

- **新课程**：粘贴公开 YouTube 视频链接时，“自动构建详尽笔记、脑图并进行第二轮自查”默认勾选。先保存基础总结，再规划和生成模块，最后独立复核并自动保存。
- **已有课程**：打开视频，点“让 AI 构建知识模块”。已有模块可通过“重建模块”重新生成。
- **独立复核**：在“自查报告”点“再自查一次”，只进行第二轮检查，不重新生成全部正文。
- **集中查看**：左侧“知识模块”显示各门课程的模块数量与待核对问题。

构建会规划一次、逐模块写详解、再自查一次，最多 8 次模型调用。长字幕可能额外需要分段提取。会使用当前 Harness 或 DeepSeek 账户的额度；不会无限重试。可以离开页面，但应保持运行知识库的终端开启。

## 脑图

脑图直接来自保存的模块和概念。根节点是主题，第一层是模块，第二层是概念。可收起或展开概念，横向或纵向滚动查看，点击模块或概念跳到对应详解。键盘也可聚焦节点并用 Enter 打开。

“下载脑图 SVG”会得到不依赖远程服务的矢量图。PDF 与无边记图片包也包含一页脑图，便于在 iPad 上手写、连线和排列。

## 两轮生成与可见自查

第一轮依据已取得的字幕或笔记规划知识结构，逐模块写详解。第二轮使用独立模型请求，对照本次资料检查依据、概念混淆、前后矛盾、遗漏与适用范围。

自查修订必须指向真实模块和具体问题，并实际改变相关字段。没有改变正文的“已修正”声明不会算作解决。程序还会检查引用编号与依据摘录，找不到的摘录会产生“待核对”问题。报告保留修订理由和仍未确认的问题。

**AI 自查不是正确性保证。** 使用同一模型的两轮请求仍可能重复同一种误解；摘录匹配只验证文字是否出现，不证明结论得到充分支持。长字幕依据分段摘录复核时，会明确标注资料范围；关键结论仍需回原视频核对。

没有足够资料时不会凭标题生成详尽模块。第二轮失败、返回格式不正确或生成期间原始资料被修改时，不覆盖已保存的模块。原来的基础总结、个人笔记和旧版备份均继续保留。

## 保存和隐私

知识模块保存在被 Git 忽略的 `data/library.json` 的视频 `knowledge` 字段中，包含模块、自查报告、模型、时间和资料指纹。个人资料不会提交 GitHub；提示词仅发送当前课程资料与本次生成的模块，不发送 OAuth 配置、API Key 或 Harness Cookie。

JSON 备份保留完整模块；PDF 与逐页图片包含模块内容、脑图和自查报告。无边记中的批注仍由无边记保存，不自动回写网站。
