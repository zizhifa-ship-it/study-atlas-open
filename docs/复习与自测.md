# 自测、AI 批改与复习计划

## 使用流程

1. 先为课程构建 AI 知识模块。模块里的复习问答会自动进入左侧“复习与自测”。
2. 选择“待复习与新题”，或按课程筛选；也可在模块中点“开始本模块自测”。
3. 不看答案，用自己的话解释，点击“提交给 AI 批改”。每次提交使用当前配置的 Harness 或 DeepSeek 模型额度。
4. 查看分数、具体反馈、遗漏知识点、参考改写与原文依据。批改成功即自动保存，不需要另点保存。
5. 部分理解和错误回答保留在“错题本”；重新答对后会离开当前错题队列，但历史作答继续保留。

“显示参考答案”不会调用模型。查看之后提交会标记为辅助练习，不增加独立答对次数。AI 反馈也会显示参考改写，因此在当前页面再次作答同题会作为辅助练习处理。

## 复习规则

| 本次情况 | 下次安排 |
| --- | --- |
| 独立答对，80–100 分 | 连续有效复习后依次为 1、3、7、14、30 天 |
| 提前再次答对 | 保留原计划，不增加跨天复习次数 |
| 部分理解，40–79 分 | 1 天后 |
| 回答错误，0–39 分 | 10 分钟后 |
| 参考后答对 | 1 天后，独立连续次数归零 |
| AI 无法判断或依据无法匹配 | 不计分，不改变上一份有效复习进度 |

时间在页面上按浏览器本地时区显示。这些是简单的练习安排，不能证明真实掌握程度，也不是经过个人校准的记忆模型。没有作答的内容只标为新题。

## 资料更新与记录保护

- 题目来自已经保存的模块，AI 批改只发送当前题目、参考答案、模块笔记、依据摘录和本次答案，不发送其他课程、账号或连接密钥。
- 批改过程中模块资料改变，结果不会写进旧题目；页面保留本次答案，可依据新资料再试。
- 重新生成模块后，如果题目、参考答案或资料变化，旧作答留在历史，当前题目重新安排。
- 保存时保留并发写入的个人批注。重复提交同一请求编号会复用已保存结果；失败不会自动无限重试。
- 未提交答案只暂存在当前页面，可以切换范围后返回；刷新或关闭页面会丢失未提交草稿。

## 备份与隐私

完整 JSON 保存题目、个人答案、AI 反馈、时间、模型与资料指纹。Markdown 导出包含知识模块、脑图文字大纲、自查与作答记录。导出文件请自行保管，不上传公开仓库。

合并导入会保留现有资料，映射导入课程的新编号，并跳过重复作答编号。当前课程与备份中的模块版本不同，旧版练习仍保留在历史，不计入当前题目的进度。

评分是 AI 对照已保存资料做出的学习建议，可能受原始笔记简化或模型误解影响。依据摘录匹配只能证明文字出现，不能独立验证技术结论。
