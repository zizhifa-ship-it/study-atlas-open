# 智能省 token

默认开启。入口在“AI / Harness 设置”，统计折叠显示，普通学习页面不增加技术信息。

## 怎样减少重复消耗

- 详尽模块：对相同提示、资料和模型，仅复用经过结构校验的响应；命中后再校验一次。资料或模型改变自动失效。独立第二轮自查仍重新调用，保留发现新问题的机会。
- 增量翻译：概览和每个模块分别缓存。只改一个模块时，其余模块和概览直接复用；只改概览时，不重译全部模块。仍检查编号、概念、问答和实验步骤数量，证据保持原语言。
- 长视频：按完整分段逐一处理，缓存有效摘录；再次整理或中断恢复时复用未变化的分段，保留尾部，不以静默截断原文换取省量。
- 紧凑 JSON：只移除 JSON 结构中的多余分隔空格，正文、代码缩进、公式、原始重复内容和所有字段原样保留。
- 脑图、PDF、无边记素材、已保存译文切换沿用本机数据，不为了显示或导出额外调用 AI。

没有降低详细笔记要求、删除来源、关闭自查，也没有换成更便宜的模型来假定效果相同。单次输出上限只是上限，不等于实际计费量，本次不靠调低上限来截短笔记。

## 复用边界

仅缓存已经通过调用方校验的模块、译文或分段摘录。网络失败、无效响应不缓存，模型请求失败不自动循环重试。缓存按任务、完整提示、服务类型与模型配置区分；更换任务或资料不会借用旧结果。

缓存不保证 AI 事实正确。内容不变时复用同一份校验结果，有助于保持内容一致；“重新自查”仍发起独立请求。需要主动重新写内容时，可关闭设置中的“智能省 token”，再执行整理；已有保存的笔记与译文仍然保留。开启后的缓存从新的生成请求开始积累。

私有响应缓存保存在 `.local/ai-cache-*.json`，最多 256 份，权限为 0600，不保存会话凭据。计数位于 `.local/ai-efficiency.json`。这些文件都受 `.gitignore` 保护，不进入 GitHub 或学习资料导出。

## 怎样看用量

设置里显示缓存复用次数和避免重复发送的输入字符数。接口明确返回用量时，另外统计对应请求的输入、输出 token；未报告的请求不猜测。字符数不等于 token 数，统计也不等于服务商账单。统计从本次更新后开始，不包含历史用量。

实际节省取决于重复整理和修改范围。第一次生成完整新课程，仍需提供足够上下文；不能承诺所有任务都有固定节省比例。隔离回归测试覆盖了内容不变、只改概览、只改单个模块、切换模型、禁用缓存、错误响应、长视频尾段和独立自查。
