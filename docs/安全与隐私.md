# 本机安全与隐私

本项目默认绑定 `127.0.0.1`，面向本机单用户。此次加固覆盖浏览器请求、外部资料读取、私有配置、异常输入和任务频率，不将它描述为“绝对安全”或可直接公开的多用户服务。

## 浏览器与本机接口

- Host 必须为当前端口的 127.0.0.1 或 localhost；Origin 必须与当前访问地址完全一致。重复 Host、跨端口来源和 `null` Origin 被拒绝。
- Fetch Metadata 为 cross-site / same-site 时，不允许读取资料、模型设置、导出或令牌接口。Google OAuth 的顶层回调导航单独允许，但仍由一次性 state 和 PKCE 校验。
- POST / PUT 额外需要 `X-Study-Atlas-Token`。页面先从同源 `/api/security` 获取每次服务启动新生成的令牌，仅保存在内存，不写入 URL、学习备份或源码。它是防跨站伪造令牌，不是账号身份认证。
- 浏览器客户端只向当前知识库的 `/api/` 路径提交令牌。服务重启后，只有明确返回 `security_token` 的 403 才刷新并重试一次；500、模型超时或其他错误不自动重发计费请求。
- CSP 限制脚本和接口连接到本站，禁止对象、外部嵌入与修改基准地址；原平台封面只允许 ytimg / hdslb 图片。页面仍使用内联样式，因此 style-src 保留 unsafe-inline；脚本不允许 unsafe-inline 或 unsafe-eval。
- 返回 DENY 防嵌入、no-referrer、nosniff、同源资源策略，并关闭本页面不需要的相机、麦克风和定位等权限。外部视频网站和系统网络配置不受影响。

## 输入、任务和私有文件

请求体最多 4 MB。拒绝缺失、重复或错误的长度、Transfer-Encoding、重复 JSON 字段、NaN/Infinity 与过深 JSON；读请求超时为 15 秒。原有资料结构校验、版本冲突、原子替换和最近 30 份备份继续保留。

每个本机服务进程在 60 秒窗口内限制：高成本 POST 30 次、其他写入 180 次、导出 6 次；超过返回 429 与 Retry-After，既有队列与模型锁仍生效。这降低误操作及部分滥用风险，不替代生产服务器或操作系统资源隔离。

`.local` 为 0700，写入配置为 0600；配置编号只允许简单标识符，拒绝配置符号链接及备份目录符号链接。日志隐藏所有 URL 查询参数并清理控制字符。缓存、转录、图片、API Key、OAuth 凭据和个人备份不在公开清单中。

## 外部访问

应用自身读取元数据、字幕和封面时，初始链接与每次 HTTP 重定向均检查视频平台域名、HTTPS、端口及用户信息。DeepSeek / Google 等带授权信息的请求与 Harness 连接不跟随 HTTP 重定向，避免凭据被意外转发。

音视频提取仍依赖 yt-dlp / PyAV 及平台提供的媒体流。本版本没有宣称对第三方工具做了完整网络沙箱，也不改变用户代理、DNS 或证书校验。应从可信来源安装并维护依赖，不应把第三方工具输出视为可信指令。

## API 脚本兼容

旧脚本若直接 POST / PUT，会收到 403。先同源 GET `/api/security`，读取 token，再把它放入请求头；不能把令牌写进 GitHub、分享链接或日志。自动化测试中的 `tests/http_helpers.py` 演示了合法调用，`api-client.js` 是网页实现。

## 验证与部署边界

`tests/test_security.py` 覆盖伪造来源、重复头、令牌、JSON、限流、回调、重定向和文件边界；JavaScript 测试覆盖令牌复用与仅限明确未执行的重试。浏览器测试验证图片、翻译、脑图、自测、保存和备份仍正常。

本次是代码和功能边界审查，不是第三方渗透认证或依赖“零漏洞”承诺。同一操作系统用户下的恶意进程仍能访问本机文件和本机服务。对外部署需要另行设计登录授权、HTTPS、生产服务器、数据隔离和审计，不能只把监听地址改成 0.0.0.0。

参考：[OWASP CSRF 防护](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)、[MDN Fetch Metadata](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Fetch_metadata)、[MDN CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP)。
