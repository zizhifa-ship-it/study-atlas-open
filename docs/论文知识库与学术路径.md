# 论文知识库与学术路径

论文知识库把“找文献”与“形成论证”放在同一个本机学习空间里。它不是论文下载器，也不替你判断论文质量；它保存可核对的题录、筛选理由、结构化精读、页码摘录和综述矩阵。

## 一条完整的学术路径

1. **检索候选**：在“论文知识库 → 加入论文”粘贴 DOI、arXiv 编号或对应链接，读取 Crossref / arXiv 的公开题录；也可以完全手动填写。
2. **筛选**：把论文标为“待筛选”“精读中”“已纳入”或“已排除”。排除也保留在库中，避免以后忘记为什么排除。
3. **精读**：在论文详情填写研究问题、方法、数据/样本、主要发现、局限、关联与可复用点；每条记录都对应一个字段，不必写成长篇自由笔记。
4. **证据**：添加页码、原文摘录和你的解释。摘录用于回看原文，解释用于连接到自己的研究问题。
5. **综述**：把已纳入论文放入“学术路径”的综述矩阵，横向比较问题、方法、数据、发现和局限。
6. **写作与引用**：在“研究问题与范围”保存检索策略、纳入/排除标准和综合论证；导出 BibTeX、RIS、Markdown 或 CSV。

## 题录与 DOI / arXiv

- DOI 会查询 `api.crossref.org`，arXiv 会查询 `export.arxiv.org`。
- 只有点击“读取公开题录”时才会发起查询；不会上传笔记、账号、学习库或个人配置。
- 公开题录可能缺摘要、作者顺序或年份；保存前请对照出版社 / arXiv 页面核对。
- 抓取失败时仍可手动填写，不影响本地保存。
- `pdfUrl` 只保存公开 PDF 链接，不把 PDF 全文上传到本机服务，也不做 OCR。

## 阶段与字段

阶段：待筛选 → 精读中 → 已纳入 / 已排除。阅读状态独立记录：未读、阅读中、已读完。

精读字段：

- 研究问题
- 方法
- 数据 / 样本
- 主要发现
- 局限
- 与本研究的关系 / 可复用点

论文证据支持页码、逐字摘录和个人解释。页码与摘录不会自动证明论文结论；仍需回到原文核对。

## 综述矩阵与引用

“学术路径”只把“已纳入”的论文放进矩阵。矩阵不是自动生成的结论，而是你已填写的字段的并排视图。

导出：

- **BibTeX**：给 LaTeX、Zotero、JabRef 等使用。
- **RIS**：给 EndNote、Zotero 等使用。
- **Markdown**：研究问题、范围、检索策略、标准、矩阵、综合论证和参考文献。
- **CSV**：方便在表格中继续比较，不包含 PDF 全文。

引用键由第一作者姓氏、年份和标题生成；同名同年的条目会自动加序号。正式投稿前请按目标期刊格式校对作者、标题、期刊名、卷期和页码。

## 保存、备份与边界

论文题录、精读、证据、综述矩阵和研究问题都保存在 `data/library.json`，包含在“完整备份 · JSON”和阅读版 Markdown 中。旧备份没有论文字段时会自动补空，不会清空已有论文；合并导入时按 DOI / arXiv / 标题去重，保留当前版本。

论文知识库面向单用户；可选的局域网模式允许已登录设备访问同一份本机资料，但不提供多人协作、在线同步、PDF 全文检索、自动引用网络或对论文质量的自动认证。不要把他人的 PDF、出版社版本或未公开稿件上传到公开 Issue；论文链接和摘要的再分发仍需遵守原论文许可。
