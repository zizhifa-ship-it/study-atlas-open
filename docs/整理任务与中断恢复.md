# 整理任务与中断恢复

左侧打开 **整理任务**，可以查看正在处理、排队、需要处理以及最近一次已完成的课程。页面只显示真实步骤与已保存的模块数量，不估算剩余分钟数。

## 中断后怎样继续

点击课程卡片上的 **继续整理**。网站按原任务类型继续知识模块、自查、翻译、版式或图文导学；仅制作基础总结的任务也保持原范围。

- 已有字幕和总结时，详尽整理直接进入知识模块，不重新读取字幕或重写总结。
- 资料、供应商、模型和推理强度均匹配时，可复用已完成的模块与自查批次。
- 模型或资料变化时，旧进度不用于新请求，页面说明原因；已经保存的笔记、人工批注和旧版总结保留。
- 旧版检查点没有足够信息确认模型时，按当前设置重新构建，避免混用来源不明的进度。
- 没有足够资料时，重新尝试获取；也可以在课程页或“质量与来源”补充 PDF、DOCX、HTML、TXT、Markdown 或字幕文件。文件先在本机读取，读取阶段不调用 AI。
- 长视频补充可选“用补充资料生成笔记”：AI 只读取本机结构摘录，不发送全文；默认作为辅助资料，不改动原字幕。也可追加、替换、仅保存、只重建知识模块或完整整理。相同内容自动去重。课程正在整理时先保存文件，当前任务结束后再重建，避免并发覆盖。网站不会凭标题编造正文。
- 翻译恢复保留原目标语言。已有的分段译文仍按来源和模型校验后复用。

**继续整理会使用当前模型的额度。** 网络或模型失败不会自动循环重试；需要点击继续。已在队列里的课程不会重复排队。服务器重启保留任务类型并标记中断，不自动调用计费模型。

## AI 设置

在“AI / Harness 设置”先选择接入方式。Harness 模式显示实际模型目录与推理强度；官方 API 模式显示模型名称和密钥输入。用量、资料获取及本机保护说明默认折叠。保存后新任务采用该选择；有未完成队列时先等待任务结束。

## 开发者验证

`GET /api/tasks` 返回课程编号、任务类型、状态、排队位置及检查点数量，不包含字幕、笔记正文、检查点全文或连接凭据。`POST /api/tasks/resume` 使用现有来源校验和写入令牌。

`tests/test_tasks.py` 用隔离数据模拟第二模块断线，验证继续后仅生成缺失模块并完成独立自查，同时检查资料/模型变化、任务范围、翻译语言、重复提交与跨站读取。`tests/browser_notes.mjs` 验证页面显示进度、点击继续、保存、刷新后完成状态以及手机布局。外部视频和模型的可用性仍取决于平台及用户配置。
