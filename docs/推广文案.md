# 试用招募文案 / Trial invitation copy

以下为可复用的发布文案。只描述已有功能，不代表已有用户数量、准确率或保证所有视频都可读取。外部平台发布请遵守对应社区规则。

## 中文短版

Study Atlas 学习图谱邀请试用：把 YouTube / B站视频、课堂文字和 Markdown 整理成康奈尔笔记、知识模块、脑图与复习题，还能导出到 iPad 无边记批注。

项目在自己电脑运行，可以连接自己的 Harness、DeepSeek API 或兼容模型服务。不配置 AI 也能先导入公开示例，查看笔记、脑图和自测题。想找朋友帮忙试试：能否顺利启动？哪里不好用？笔记结构是否方便复习？

试用步骤：https://github.com/zizhifa-ship-it/study-atlas-open/blob/main/docs/试用与反馈.md

反馈入口：https://github.com/zizhifa-ship-it/study-atlas-open/issues/new?template=03-trial-feedback.yml

这是测试阶段的源码公开项目。AI 需要自己的模型服务；视频资料获取受平台与网络限制。非商业用途免费，新内容商业许可与旧 MIT 权利以仓库许可说明为准。

## English

Try Study Atlas: a local-first learning library for YouTube / Bilibili videos, classroom text and Markdown. Organize materials into Cornell notes, knowledge modules, mind maps and review questions, with export for reading and iPad Freeform annotation.

Connect your own model, or start with the prewritten public sample without an AI key. We would love feedback on installation, confusing steps and whether the note structure helps you review. The interface is currently primarily Simplified Chinese.

Start here: https://github.com/zizhifa-ship-it/study-atlas-open/blob/main/docs/试用与反馈.md

Feedback: https://github.com/zizhifa-ship-it/study-atlas-open/issues/new?template=03-trial-feedback.yml

Beta, source-available software. Model access, video availability and optional export dependencies vary. Noncommercial use is free; see the repository for new-material commercial licensing and preserved legacy MIT rights.
