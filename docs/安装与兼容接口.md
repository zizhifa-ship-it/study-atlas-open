# 安装、首次使用与独立模型接入

Study Atlas 面向每个人在自己电脑上安装。下载公开源码不会带入作者或其他人的资料、模型密钥、Cookie 或缓存。界面目前主要使用简体中文。

## 1. 启动网站

先安装 Python 3.9 或更新版本，解压项目到自己的用户目录。核心收藏、文字资料、笔记与 JSON / Markdown 备份只使用 Python 标准库，不需要 Node.js、数据库或 AI 密钥。

| 系统 | 启动方式 |
|---|---|
| Windows | 双击 `start.bat`；或在项目目录执行 `py -3 server.py --open` |
| macOS | 在项目目录执行 `sh start.sh`；若使用 `.command`，先给该文件执行权限 |
| Linux | 在项目目录执行 `sh start.sh` |

启动器优先使用项目的 `.venv` 环境，然后寻找系统 Python。带空格的项目路径可正常传入。端口已占用时可运行 `sh start.sh --port 8766` 或 `start.bat --port 8766`。网站只监听 `127.0.0.1`，在本机浏览器打开，不开启局域网或公网访问。

Unix 文件权限限制仍保留。Windows 不提供同样的 Unix 权限位，文件继承目录 ACL；请使用自己的用户目录与 Windows 账户保护资料，不把项目工作目录放进公开共享文件夹。

## 2. 从首次使用页开始

打开左侧“首次使用 / 环境自检”。自检只查看本机配置，不联网测试、不安装软件、不下载模型，也不会触发计费生成。“按需配置”表示可选能力未准备好，基础功能仍能使用。

可以先点“导入文字资料”，保存 TXT、Markdown、SRT、VTT 或平台字幕 JSON。无需填虚构的视频链接。TXT / Markdown 的代码、缩进和换行保留；字幕格式会移除时间轴标记。每份有效正文为 20 至 200000 字符，文件最多 800 KB；PDF / Word 目前需先自行提取文字。

不勾选自动整理时，仅保存原文，之后可补充批注。原文位于该课程“查看原始资料”入口。配置好模型后，点击“让 AI 构建知识模块”，即可生成详尽笔记、康奈尔结构、脑图与复习问答；译文、自查和自测也使用当前模型。

## 3. 不依赖 Harness 的 AI 接入

在“AI / Harness 设置”的“整理时使用”选择“兼容接口 / 独立本机模型”。

| 服务 | Base URL | 凭据 |
|---|---|---|
| Ollama | `http://127.0.0.1:11434/v1` | 本机通常可留空 |
| LM Studio | `http://127.0.0.1:1234/v1` | 按本机服务设置 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | 自己的硅基流动 API Key |
| OpenRouter | `https://openrouter.ai/api/v1` | 自己的 OpenRouter API Key |

本机模型需由使用者安装、下载并开启服务。先选择服务与地址，可点“读取该服务的模型列表”，选中实际提供的模型 ID，再保存。模型列表读取不会生成内容；若服务不提供列表或目录超过展示上限，可手动填写模型 ID。页面最多展示 300 个模型。

本机接口仅允许回环地址，端口可修改；云端地址固定为上表官方地址，不接受任意 URL。连接不跟随重定向。本机接口绕过请求级代理，不改变系统代理、DNS 或浏览器设置。接口使用非流式 Chat Completions，模型必须能返回完整的文本与所需 JSON；不保证所有模型质量、上下文长度或服务商附加功能一致。

密钥按供应商分开保存，修改本机地址也不会沿用旧地址的密钥。其他服务不会拿到 Harness、Google 或 DeepSeek 的凭据。切换供应商、接口或模型会隔离生成缓存；中断任务也按当前来源与模型检查进度。已有笔记保留，模型失败不会自动换服务或反复重试。

接入协议参考：[Ollama 官方兼容说明](https://github.com/ollama/ollama/blob/main/docs/api/openai-compatibility.mdx)、[LM Studio 官方兼容接口](https://lmstudio.ai/docs/developer/openai-compat)、[硅基流动聊天接口](https://docs.siliconflow.cn/docs/api/chat-completions-post)、[OpenRouter 官方开发入口](https://openrouter.ai/developers)。服务可用性、模型目录、费用与额度以使用者账户为准。

## 4. 按需安装可选能力

推荐在项目内创建虚拟环境，不需要改动系统 Python：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt yt-dlp
```

Windows 使用：

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt yt-dlp
```

上面的依赖用于 PDF / 无边记导出与视频提取；纯文字入库不需要它们。YouTube 提取还可能需要 Node.js。中文 PDF 需要可用的中文字体：项目会查找 Windows 微软雅黑 / 宋体、macOS Arial Unicode 和部分 Linux 字体，也可通过 `STUDY_ATLAS_PDF_FONT` 指定本机 TTF / TTC 文件。字体不会被上传。

本机音轨转录另外需要 Python 3.10+，运行 `python tools/setup_transcription.py`；此步骤会创建 `.venv-asr` 并下载多语言模型。CPU 速度、内存、平台音轨可访问性和识别准确率取决于设备与视频。

## 5. 升级与迁移

先在旧版本导出完整 JSON，再解压新版到另一个目录并导入备份。保留旧目录用于回退。合并导入会保留已有版本，跳过重复来源；课堂资料也可完整迁移。原始资料在 JSON 中保存，阅读版 Markdown / PDF 导出的是已保存笔记，不替代完整备份。

密钥、OAuth、Harness 登录、可选模型及截图缓存不随 JSON 备份迁移。到新电脑后重新配置所需连接；视频画面可重新生成。

## 6. 验证范围

`tests/browser_community.mjs` 使用空白临时库与模拟模型，验证首次引导、无密钥导入、代码保留、模型目录、知识模块、刷新和备份合并。`tests/test_community.py` 验证本机临时兼容服务、凭据隔离、接口限制和启动参数。

公开仓库的 CI 配置覆盖 Windows、macOS、Linux 与 Python 3.9 / 3.12 的启动和新用户测试，并在 Linux 执行完整回归。CI 的实际运行结果请查看仓库 Actions；配置文件本身不代表所有平台已经通过。浏览器端到端测试仍需额外安装 Playwright 与浏览器。
