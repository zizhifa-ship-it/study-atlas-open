# 笔记、翻译与资料来源

## 日常阅读

粘贴公开 YouTube 链接，等待后台整理。主页面显示康奈尔笔记、脑图、流程、课程来源与复习入口。左侧“质量与来源”单独保存自查结果、修订说明、资料编辑、模型和失败原因，每门课默认收起。

## 不依赖中文翻译字幕

1. 优先复用本机已有资料与缓存。
2. 读取公开视频元数据，只挑原语言的人工/自动字幕，排除 `tlang` 翻译轨道。
3. 原字幕受限或不存在时，可选本机 faster-whisper 识别公开音轨。字幕 429 不会触发反复请求或翻译轨道重试。
4. 两条路径都不能取到资料时，提示导入 TXT、SRT、VTT 或 JSON3，也可粘贴原始资料。没有内容就不编造笔记。
5. AI 根据原语言资料直接制作中文总结、知识模块和复习问答。

本机 ASR 需要先运行安装脚本，默认多语言 base 模型。临时音轨在任务结束后删除，缓存、模型和设置仅在 `.local/`、`.venv-asr/` 中。网站不修改系统代理、DNS、浏览器或 YouTube 播放设置。私人或受保护视频不在自动获取范围。

## 多语言笔记

在课程详情“笔记语言”选择目标语言，首次点“生成某语言笔记”。完成后自动切换，保存后再次切换无需重复调用 AI。支持中文、英语、德语、日语、韩语、法语、西班牙语、俄语。页面按钮保持中文。

翻译按课程概览和每个模块分别生成，内容包括正文、概念、例子、易错点、康奈尔提示和小结、实验流程、复习问答。代码、公式和引用编号保留，原始依据摘录保留原语言。中文原稿不覆盖，可展开对照。AI 翻译仍可能出错。

后台按原稿指纹判断译文有效性。修改原稿后提示重新生成；修改个人批注不会使译文失效。中途失败保留已完成模块，手动重试从检查点继续。生成期间原稿变更时不覆盖新内容。

## 导出与隐私

单课 PDF、无边记图片包和 SVG 使用当前已生成语言版本。全库 PDF 使用中文。Markdown 导出遵循当前各课程选择，JSON 包含全部译文。阅读导出不含原字幕全文和连接凭据，JSON 是私人学习备份，请自行保存。

仅开源代码、测试、文档和空白示例。个人资料、API Key、OAuth 凭据、模型、缓存、音轨与导出笔记都不进入公共源码包。

## 输入语言与输出语言

原视频的语言自动识别，字幕与转录都可作为原语言资料，AI 直接制作中文笔记。“笔记语言”中的八个选项是输出版本，不是输入视频语言限制。转录准确性仍取决于模型对该语言、口音与术语的支持。B站和视频画面说明见 [哔哩哔哩与图文笔记](哔哩哔哩与图文笔记.md)。
