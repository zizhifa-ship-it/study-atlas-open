# 把 AI 笔记带到 iPad 无边记

日常流程是：**粘贴视频链接 → AI 自动分类并写好中文笔记 → 导出到无边记 → 你手写、连线和补充自己的理解**。

## AI 完成什么

公开 YouTube 链接会自动识别标题、作者、可用字幕，生成中文学习标题、分类、标签和笔记。笔记包含知识脉络、概念、课程中的例子、易错点、复习问题与下一步练习。英文原始标题保留在来源中，便于核对。

字幕较长时，按每段最多 8 万字符提取要点，再综合所有分段。不静默截掉后半部分；分段摘要仍可能遗漏细节，请结合原视频核对。进度会显示当前处理的分段。资料没有字幕时只分类，不编造正文。

“AI 自动写好笔记”和“归纳共通经验”都会自动保存。重新整理会把不同的旧总结存为补充笔记；如果你在生成过程中修改正文，会保留你的正文并把新 AI 结果另存为补充。批量入口位于“学习笔记 → AI 整理待办”，最多依次安排 20 条尚未完成的公开 YouTube 视频，不自动重复重试。

## 导出哪一种

已构建知识模块时，PDF 与图片还包含脑图、各模块详解和自查报告。

视频详情可以导出当前课程，“学习笔记”与“导出与备份”可以导出全部已保存内容。

- **无边记素材包（ZIP）**：含逐页 PNG、原稿 PDF 与使用说明。PNG 方便放在无限画布上排列、连接和手写，每页右侧有留白。
- **PDF**：保留可选择的中文文字、原视频来源链接、分页与手写练习页，适合阅读和归档。
- **JSON**：保留完整分类、原始字幕、总结、旧版和补充笔记，可恢复网站资料；它不是无边记的导入文件。

导出不会调用 AI、不会消耗模型额度，也不会上传资料到 GitHub。PDF 与图片不包含账号、密钥、Harness Cookie 或原始字幕全文。旧版总结留在 JSON，阅读版不重复排印历史全文。

## iPad 上操作

1. 在 Mac 下载素材包，通过 AirDrop 或你自己保管的 iCloud 云盘传到 iPad。
2. 在 iPad 的“文件”里轻点 ZIP 解压，进入“图片”目录。
3. 在无边记新建看板，分屏打开“文件”，将需要的 PNG 图片拖入画布；也可插入 PDF 作为原稿附件。
4. 调整图卡大小与排列，用 Apple Pencil 或手指手写，也可以加文本框、便笺条与连线。
5. 批注由无边记保存。需要带批注的归档文件时，从无边记导出 PDF。

PNG 里的文字是图片，不能直接改字；想修改原稿文字，请在学习图谱修订后重新导出。网站与无边记之间没有自动双向同步，重新导出不会自动带回你在无边记里的批注。AI 原稿与带批注副本请分别保留。

无边记支持添加图像、PDF 和其他文件，具体菜单因 iPadOS 版本有所不同。参考 [Apple 无边记使用说明](https://support.apple.com/zh-hans/guide/ipad/ipade453ddaa/ipados)。

## 首次安装导出组件

基础知识库仍只用 Python 标准库。PDF 与图片导出需要额外的本机组件；不会安装到系统 Python，也不改变代理、DNS 或浏览器设置。推荐独立环境：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --open
```

Mac 使用系统已有的 Arial Unicode 中文字体，字体文件不会随源码分发。其他系统可通过 `STUDY_ATLAS_PDF_FONT` 指定自己的中文 TTF 字体；通过 `STUDY_ATLAS_PDF_PYTHON` 指定已安装依赖的 Python。若本机有 Codex 捆绑的文档运行时，程序可复用已有组件，无须重复安装。

知识库默认仅监听 Mac 本机地址。iPad 上的 `127.0.0.1` 指的是 iPad 自己，因此跨设备使用这里的导出文件，不会把私人知识库直接公开到网络。
