# Study Atlas v0.1.0-beta.1 · 邀请试用 / Public beta

把学习视频和课堂资料变成可以阅读、批注、关联和复习的知识库。欢迎反馈首次启动、资料导入及笔记使用中最不顺的一步。

A local-first learning library for videos and class materials. Try the sample, explore Cornell notes and mind maps, and tell us what helped or got in your way. The interface is currently primarily Simplified Chinese.

## 下载后这样开始 / Quick start

1. 下载本页 Assets 中的 **Source code (zip)** 源码包（需 Python 3.9+），解压到自己的用户目录。
2. Windows 双击 `start.bat`；macOS / Linux 执行 `sh start.sh`，打开 `http://127.0.0.1:8765`，保持终端运行。
3. 按 [首次试用指南](https://github.com/zizhifa-ship-it/study-atlas-open/blob/v0.1.0-beta.1/docs/试用与反馈.md) 导入包内 `examples/demo-library.json`。这个预置示例有 3 个知识模块、6 道复习题，无需模型密钥即可阅读、查看脑图和添加批注。它是预写教学样例，不是实时 AI 生成效果。

Download the source ZIP, install Python 3.9+, run `start.bat` or `sh start.sh`, and import `examples/demo-library.json` from the local backup menu. Read the [first-use guide](https://github.com/zizhifa-ship-it/study-atlas-open/blob/v0.1.0-beta.1/docs/试用与反馈.md) for the prewritten sample and optional setup.

## 可以尝试 / What to try

- 导入公开 YouTube / 哔哩哔哩链接，或课堂文字、Markdown、字幕；整理分类与个人补充。
- 连接自己的 Harness、DeepSeek API、Ollama、LM Studio、硅基流动或 OpenRouter，生成知识模块、康奈尔笔记、脑图、翻译和复习题。
- 用已保存的问题自测；连接模型后可批改并保留错题。导出 JSON / Markdown，或按需安装依赖后导出 PDF / iPad 无边记素材。
- 新增了首次试用入口、公开示例、双语反馈表及功能示意。文字课程的模块来源入口可返回站内原始资料。

## 测试阶段与边界 / Beta scope

这是每个人在自己电脑运行的测试版，不是已部署的多人云服务。模型生成与翻译需自己的连接和额度，本机模型需自行安装。视频字幕及音轨可访问性受平台和网络限制；资料不足时不保证能生成完整笔记。AI 自查不是正确性保证。PDF 与无边记导出需要可选依赖和中文字体，批注暂不双向同步。

This beta is for individual local installation. Model access, video availability and optional export dependencies vary. Review AI output against its source; handwritten annotations do not sync back automatically.
