# 哔哩哔哩与图文笔记

## 使用

点“粘贴链接一键整理”，粘贴 B站 BV/av 视频链接或 b23.tv 分享链接，保留详细整理勾选。分 P 课程先在 B站点开要学的那一集，再复制地址；网站只整理所选这一集，无集数参数时为第 1 P。分享文字中的单个视频链接也能识别。

后台读取标题、作者、时长、真实封面，获取讲课字幕；无可公开读取字幕时，用可选本机转录识别原语言音轨。字幕和语音识别都不限制为中文输入，直接交给已连接的 AI 制作中文学习笔记。已保存笔记也可另选目标语言生成副本。

## 图文导学

课程详情中的图文导学展示真实封面和最多三张真实视频画面，画面标注时间并可跳回原视频。当模块原文依据能在字幕时间轴匹配时，用模块名说明关联；否则只显示“视频画面”。笔记主要根据字幕/转录形成，系统不会声称已用视觉模型读懂截图。

普通笔记按康奈尔提示、课堂记录、归纳小结组织。实验课程另外展示目标、条件、操作、预期和验证方法。脑图、自测、多视频经验归纳、PDF 与无边记导出沿用现有流程。自查报告、来源、历史总结和失败详情在“质量与来源”，默认收起。

## 依赖和边界

第一次可运行“安装本机转录.command”，建立 `.venv-asr`、安装 faster-whisper/PyAV 并下载多语言模型。没有安装时，能用公开字幕整理，封面也可以显示；本机转录和画面提取需要额外组件。

只读取用户指定的公开视频。不自动读取浏览器 Cookie、账号、观看历史，不绕过会员、私人视频、验证码或地区访问限制。字幕不可用时本机转录依赖可访问的公开音轨；两者都不可访问时导入 TXT/SRT/VTT/JSON 转录文件即可继续。

临时音轨随任务结束删除。私有缓存中的原文、模型、封面和截图不会传到 GitHub。文字材料按配置发送给所选 AI 服务；截图由本机提取，不发送到额外视觉服务。

JSON 备份包含笔记与图文索引，不嵌入所有图片；转移电脑后可重建画面。PDF、逐页 PNG 素材包已经包含图片，适合在 iPad 无边记做批注。无边记里的批注不会自动回写网站。

实现参考：B站公开视频/播放器接口，以及 [yt-dlp Bilibili 提取器](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py)。
